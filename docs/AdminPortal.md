# Admin Web App Specification

## Route & Access
- Route: `/#/admin`
- Default Credentials: `admin@addus.in` / `addus@admin2025`

## Modules & Tabs
1. **Businesses**: Search, filter by industry, inspect full Business Brain drawers.
2. **Expert Review Queue**: Review pending requests, assign team members, publish expert notes.
3. **Projects**: View all user projects across all statuses.
4. **Users**: User account lookup, authentication method tracking, project counts.
5. **Notifications**: Compose custom or templated notifications to user dashboards.
6. **Analytics**: Overview of total businesses, active projects, revenue, and industry breakdown.
