# Customer Web App Specification

## Target Persona
Business owners, startup founders, brand managers.

## Key Workflows
1. **Phone/Email OTP Auth**: User authentication with automatic account lookup and returning-user session restore.
2. **Business Intake**: Multi-format Business Upload Widget (URL, document drag-drop, text) with real-time AI extraction.
3. **Business Brain**: Editable Business Summary card showing AI confidence score.
4. **Expert Review**: Automated status tracking for expert recommendations.
5. **Project Customization & Booking**: Visual calendar booking with minimum 3-day buffer enforcement, agency proposals, and automatic dashboard redirect.
6. **Dashboard Workspace**: Active project workspace, project status tracking, and continuous ADDI chat strip.
